Developer API

Integrate PhishWatch's XGBoost detection engine directly into your own applications, firewalls, or browser extensions using our REST API.

POST /predict/

Submit a URL for real-time analysis. The API extracts 16 features on the fly, runs them through the XGBoost model, and returns a JSON verdict with confidence scoring.

Request Format (cURL)

curl -X POST http://127.0.0.1:8000/predict/ \ -H "Content-Type: application/x-www-form-urlencoded" \ -d "url=https://secure-login-update.com"

Response Payload (JSON)

{ "url": "https://secure-login-update.com", "is_phishing": true, "confidence": 96.4, "features": { "// 16 extracted structural features" "URL_Length": 1, "Having_@_symbol": 0, "Prefix_Suffix": 1, "...and 13 more" } }
